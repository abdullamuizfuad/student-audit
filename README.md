# Digital Presence Audit, Student Edition

A free audit tool for e-marketing students (MKT303). Students check a business's social media, Google Business Profile, website and reviews, then edit a draft 12-month plan and download a PDF.

Runs fully in the browser. No server, no database, nothing uploaded. Screenshots stay in the page and go into the PDF appendix.

## Publish with GitHub Pages
Settings, Pages, Source: Deploy from a branch, Branch: main, folder: / (root).

## Files
- `index.html` the page
- `core.js` scoring rules and draft-plan rules (no AI)
- `ui.js` screens, `pdf.js` PDF report, `student-audit.css` styles
- `assets/` Islandeative stylesheet and logo, `pdf/` PDF fonts (Archivo and Figtree, OFL)
